英文翻译学习助手 · 设置

划词模式

快捷键 Alt+Shift+T（Mac 为 ⌥⇧T）可随时开关划词翻译，浏览器图标上会显示 ON/OFF 角标。

双语对照阅读

逐段模式按需请求，不会触发 Google 免费接口的 429 限流；翻过的段落有缓存，不重复请求。

快速翻译引擎

获取方式：腾讯云控制台 → 机器翻译 TMT → 开通服务 → API 密钥管理。

获取方式：百度翻译开放平台 fanyi-api.baidu.com → 注册并开通通用文本翻译 → 管理控制台查看 APPID 和密钥。

朗读引擎

获取方式：百度智能云控制台 → 语音技术 → 应用管理 → 创建应用（勾选语音合成）。注意这与百度翻译的 APPID 不是同一套凭证。

选择腾讯朗读时：需已配置腾讯 SecretId/SecretKey，并到语音合成控制台领取免费资源包；任一在线引擎失败都会自动回退系统语音。

深度讲解引擎

选择豆包网页版时，请确保已在 Chrome 中登录 www.doubao.com 且能正常对话；讲解请求会使用你的豆包账号，对话记录会留在豆包账号里。

Key 仅保存在本地浏览器（chrome.storage.local），不经过任何第三方服务器。DeepSeek / Kimi / 通义 / OpenAI 等 OpenAI 兼容接口均可使用。
